# 🌐 Maseer Portal

GitHub Pages-hosted registration form for Maseer Media Inc.

## 🚀 Live URL
`https://hasinamusadiq.github.io/maseer_portal/ `

## ✨ Features
- Multi-step bilingual form (English/Persian)
- Direct logo upload (PNG, JPG, SVG)
- Professional purple/yellow color theme
- Mobile responsive design
- Automatic GitHub Issues creation

## 🛠️ Setup
1. Update `CONFIG` in `assets/js/app.js` with your GitHub username
2. Push to GitHub
3. Enable Pages in Settings → Pages
