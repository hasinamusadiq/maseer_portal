# 🌐 Maseer Portal

GitHub Pages-hosted registration form for Maseer Automation.

## 🚀 Live URL
`https://hasinamusadiq.github.io/maseer-portal/`

## ✨ Features
- Multi-step bilingual form (English/Persian)
- Professional color picker (Coloris.js)
- Logo preview and validation
- Mobile responsive
- Submits to GitHub Issues

## 🛠️ Setup
1. Update `CONFIG` in `assets/js/app.js` with your GitHub username
2. Push to GitHub
3. Enable Pages in Settings
