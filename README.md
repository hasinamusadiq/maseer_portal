# 🌐 Maseer Portal

GitHub Pages-hosted registration form for Maseer Media Inc.

## 🚀 Live URL
`https://hasinamusadiq.github.io/maseer_portal/`

## ✨ Features
- Multi-step bilingual form (English/Persian/Pashto)
- Direct logo upload (PNG, JPG, SVG)
- Professional purple/yellow color theme
- Mobile responsive design
- Automatic GitHub Issues creation
- Consciousness-based UX with frequency animations

## 🛠️ Setup
1. Update `CONFIG` in `assets/js/app.js` with your GitHub token
2. Push to GitHub
3. Enable Pages in Settings → Pages

## Required Secrets
- `GITHUB_TOKEN` - Personal access token with repo scope

## 📁 Structure
- `index.html` - Main registration form
- `success.html` - Confirmation page
- `assets/js/` - JavaScript modules
- `assets/css/` - Stylesheets
